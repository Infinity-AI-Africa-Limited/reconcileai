# ReconcileAI Logo Suite — 17 August 2026

## Design direction

The proposed identity uses a dark-navy operational-control field, four structured
data/ledger rails, and a coral checkmark bridge. The mark expresses the core product
promise: fragmented transaction evidence converges into a verified reconciliation
outcome. It is intentionally distinct from the Infinity AI infinity mark while
remaining compatible with the wider Infinity AI visual family.

| Asset | Review status | Intended use |

| Combined wordmark | Created | Website, decks, proposals, and public product identity. |
| Standalone mark | Created | Product surfaces, documents, and compact brand placements. |
| 120×120 App Store icon | Created | SHOPLINE listing, subject to Richard’s approval. |

## Review observations
